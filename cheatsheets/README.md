# Cheat sheets

Your offline reference — lookup tables and three-line examples, for when
you need an answer in ten seconds and the module README is too long.

| sheet | what's in it |
| --- | --- |
| [csharp-language.md](csharp-language.md) | types, numbers, null, strings, patterns, methods, delegates, exceptions, time, regex, spans |
| [linq.md](linq.md) | every operator you'll use, what it costs, what it throws, and which ones are lazy |

The three shelves divide like this:

| shelf | shape | reach for it when |
| --- | --- | --- |
| `cheatsheets/` | lookup tables | you need an answer in ten seconds |
| `bootcamp/*/README.md` | 10-minute lessons | you are about to write code |
| `solutions/*.cs` walkthroughs | the why behind one answer | you just attempted that exercise |

Verified against .NET 10 / C# 14 on Windows.
