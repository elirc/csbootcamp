# Quizzes

Rapid-fire recall, one file per module, answers hidden behind `<details>`.

They are not a test you pass; they are a retrieval exercise. **Say the
answer out loud before you expand it.** Speaking it is the rep — reading
the answer and thinking "yes, I knew that" is recognition, which feels the
same and is not.
